## Material personal y entrega pendiente

La identidad se toma de `../recursos-compartidos/`; no de los estilos antiguos
de Angular. El CV puede ser A4 si conviene como documento independiente: no
tiene que encogerse para coincidir con el A5 del librito.

Los originales con datos personales pueden guardarse en `privado/`, excluido
de Git. Esta carpeta no se incorpora a la demo. Queda pendiente decidir qué
documentos acompañarán a la entrega impresa.
