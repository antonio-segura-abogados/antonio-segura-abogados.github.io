# Recursos compartidos

Fuentes, colores, estilos e imágenes comunes al librito, al vertical y a los
anexos. `estilos/tokens.css` contiene la paleta y los roles elegidos;
`estilos/fuentes.css` define las fuentes locales y `estilos/base.css` los
estilos generales. La adaptación de impresión está en `../librito/`.

Los datos observados y las decisiones propias se distinguen en
[identidad-visual.md](investigacion/identidad-visual.md). Consultar el
[catálogo](investigacion/catalogo-assets.md) antes de elegir una imagen para
imprimir: incluye dimensiones, procedencia y limitaciones.

`investigacion/web/` conserva las descargas HTML/CSS de la web como evidencia
local; está excluida de Git y no se ejecuta ni se carga en la aplicación.
