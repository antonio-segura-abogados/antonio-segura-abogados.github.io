# Capturas de la demo para las páginas 08–13

Capturas reales de las escenas React del proyecto, con perfil temporal de
Chrome y escala 3×. El dispositivo, pantalla, esquinas, controles y barra
superior se dibujan con HTML/CSS en `vertical/src/components/DemoScene.tsx` y
`vertical/src/product.css`. No son imágenes de otra aplicación.

[procedencia.json](procedencia.json) conserva las rutas y la verificación.
[capturar.mjs](../../../../librito/muestras/08-13-app/capturar.mjs) permite
reproducirlas desde un servidor local. Los textos del ejemplo están en
`recursos-compartidos/demo/entrada.json` y `seguimiento.json`.

`11-contratacion.png` documenta el resumen de compra disponible como escena
autónoma y como panel. La página impresa 11 utiliza `11-planes.png`, con los
precios ampliados fuera del teléfono. Todas las capturas emplean datos ficticios.
